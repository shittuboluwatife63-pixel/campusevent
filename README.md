# Campusly

Campusly is a campus events discovery app built with Next.js. Browse upcoming
events, find something that interests you, and save it to your personal event
list.

## Features

- Browse campus events displayed as responsive cards.
- Filter events by category: Tech, Sports, Faith, and Social.
- Search events by title and sort them by date.
- View event details, including the date, time, venue, and a countdown.
- Save and remove events from **My Events**. Saved events persist in your
  browser using local storage.
- Responsive layouts, category badges, and interactive card hover effects.
- Helpful empty states when no events match your search or saved list.

## Tech Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS
- JavaScript

## Getting Started

### Requirements

- Node.js
- npm

### Install and run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production build

```bash
npm run build
npm run start
```

## Project Structure
- `app/` - pages and layouts
